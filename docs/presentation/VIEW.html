1. 한 줄 스토리

온프레미스에서 Nginx · Django · NFS · MariaDB 4대 서버로 운영하던 Aniverse를
AWS 관리형 서비스로 옮기고, Terraform + GitHub Actions + CodeDeploy로 자동화했다.

도메인: https://aniverse.my (HTTPS · WAF · 자동 배포)

앱 기능 개발 (4인) → 온프렘 4서버 → AWS 모듈 분담 → CI/CD 자동화

8. 발표 멘트

“앱은 기능 담당으로 만들었고, 클라우드 이전에서는 역할을 다시 나눴습니다.
서이 네트워크·보안, 유민 ALB·ASG, 윤주 RDS·EFS·S3,
저는 모듈을 조립하고 Terraform·GitHub Actions로 자동화했습니다.
HTTPS·WAF·Secrets까지 넣었고, 지금은 aniverse.my 로 서비스 중입니다.”
